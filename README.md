# Enterprise Linux Security Tools

Install security assessment tools for Enterprise Linux.

This isn't meant to replace full security distributions such as Kali Linux, Parrot or the like. This toolkit is intended for genuine, ethical and authorised security research, security assessement, and security hardening for Enterprise Linux systems and environments. Useful for security focused Systems Administrators and security researchers.

These tools can be used for:
- Assessing the security of Enterprise Linux servers that you own.
- Assessing the security of Web Applications running on Linux servers that you own.
- Threat Hunting on Enterprise Linux systems.
- Analysing the compliance status of Enterprise Linux servers that you own.

Currently tested and working on EL version 9, including:
- RHEL
- Oracle Linux
- Rocky Linux
- Alma Linux

## Instructions

Clone the repo and run from Bash.
Should be run as a regular user with sudo privileges.

Ideally you will be installing this on a 'Server with GUI' or Workstation installation of Enterprise Linux as it does install some GUI tools.

## Disclaimer
Some of these tools could be considered dangerous or malicious.

Don't install these tools in a production environment or on production servers without proper permission and authorisation.

Don't test systems that you do not own or do not have permission to test.
